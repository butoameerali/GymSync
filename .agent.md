# AI SaaS Platform: Master Architecture & Execution Guide

## 🎯 Project Overview

**Platform:** Full-Stack AI SaaS for AI video generation with geo-restrictions, daily quotas, and monetization.

| Component | Tech Stack | Purpose |
|-----------|-----------|---------|
| **Frontend** | Next.js 14/15 (App Router, JavaScript .jsx), Tailwind CSS | User interface, tool pages, video player |
| **Backend** | Python FastAPI (port 8000) | AI orchestration, Flow AI integration, async task workers |
| **Database & Auth** | Supabase (PostgreSQL + Auth) | User profiles, quotas, subscription tiers, RLS security |
| **Video Generation** | Flow AI (Google Labs) | 14 credits per 8-second video generation |

### Target Audience & Monetization
- **Primary:** Video generation free tier **RESTRICTED to Tier-1 countries** (US, CA, AU)
- **Secondary:** Non-allowed regions require **Premium subscription**
- **Tertiary:** Basic utility tools (PDF merge, image resize, etc.) **open globally with ads**

## 📊 Database Schema (Supabase PostgreSQL)

### 1. Profiles Table
Tracks user role, subscription tier, and country for geo-restrictions.

```sql
CREATE TABLE public.profiles (
    id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
    email TEXT NOT NULL,
    role TEXT DEFAULT 'user' CHECK (role IN ('user', 'admin')),
    subscription_tier TEXT DEFAULT 'free' CHECK (subscription_tier IN ('free', 'ad_free', 'premium')),
    country_code VARCHAR(5) DEFAULT 'UNKNOWN',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### 2. Daily Video Quotas Table
Enforces 2 videos/day limit for free users.

```sql
CREATE TABLE public.video_quotas (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES public.profiles(id) ON DELETE CASCADE,
    generation_date DATE DEFAULT CURRENT_DATE,
    count_today INT DEFAULT 0,
    CONSTRAINT unique_user_per_day UNIQUE (user_id, generation_date)
);
```

### 3. Dynamic Tools Registry
Admin-managed table for enabling/disabling tools dynamically.

```sql
CREATE TABLE public.tools (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name TEXT NOT NULL,
    slug TEXT UNIQUE NOT NULL,
    category TEXT NOT NULL,
    requires_login BOOLEAN DEFAULT false,
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Row-Level Security (RLS)
```sql
ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;
```

## 🔑 Approach #1: Direct API Integration (Recommended)

### Prerequisites
1. Active Flow AI account with API credentials
2. Extract session token and authorization headers
3. Backend environment variables configured

### Backend: FastAPI Endpoint (`backend/routes/video_gen.py`)

```python
import os
import asyncio
import httpx
from fastapi import APIRouter, HTTPException, Depends
from pydantic import BaseModel
from datetime import datetime

router = APIRouter()

# Environment Configuration
FLOW_SESSION_TOKEN = os.getenv("FLOW_SESSION_TOKEN")
FLOW_API_URL = os.getenv("FLOW_API_URL", "https://api.flowai.com/v1/generate")
FLOW_STATUS_URL = os.getenv("FLOW_STATUS_URL", "https://api.flowai.com/v1/tasks")

class VideoRequest(BaseModel):
    prompt: str
    user_id: str
    duration_seconds: int = 8
    aspect_ratio: str = "16:9"

@router.post("/api/flow-video")
async def generate_flow_video(payload: VideoRequest):
    """
    Trigger Flow AI video generation with 14 credits.
    Returns task_id for polling.
    """
    if not payload.prompt.strip():
        raise HTTPException(status_code=400, detail="Prompt cannot be empty")
    
    if not FLOW_SESSION_TOKEN:
        raise HTTPException(status_code=500, detail="FLOW_SESSION_TOKEN not configured")

    headers = {
        "Authorization": f"Bearer {FLOW_SESSION_TOKEN}",
        "Content-Type": "application/json",
        "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36"
    }

    api_payload = {
        "prompt": payload.prompt,
        "duration": payload.duration_seconds,
        "aspect_ratio": payload.aspect_ratio,
        "credits": 14
    }

    try:
        async with httpx.AsyncClient(timeout=30.0) as client:
            response = await client.post(FLOW_API_URL, json=api_payload, headers=headers)
            
            if response.status_code == 401:
                raise HTTPException(status_code=502, detail="Flow AI session expired. Admin needs to refresh token.")
            if response.status_code not in [200, 201, 202]:
                raise HTTPException(status_code=response.status_code, detail=f"Flow API error: {response.text}")
            
            res_data = response.json()
            task_id = res_data.get("task_id")
            
            return {
                "status": "processing",
                "task_id": task_id,
                "estimated_wait_seconds": 25
            }
    
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))


@router.get("/api/flow-video/{task_id}/status")
async def check_video_status(task_id: str):
    """
    Poll Flow AI for generation status.
    Client should call this every 3 seconds.
    """
    if not FLOW_SESSION_TOKEN:
        raise HTTPException(status_code=500, detail="FLOW_SESSION_TOKEN not configured")

    headers = {
        "Authorization": f"Bearer {FLOW_SESSION_TOKEN}",
        "Content-Type": "application/json"
    }

    async with httpx.AsyncClient(timeout=10.0) as client:
        response = await client.get(f"{FLOW_STATUS_URL}/{task_id}", headers=headers)
        
        if response.status_code == 401:
            raise HTTPException(status_code=502, detail="Session expired")
        
        data = response.json()
        
        return {
            "task_id": task_id,
            "status": data.get("status"),  # "processing" | "completed" | "failed"
            "progress": data.get("progress", 0),
            "video_url": data.get("video_url") if data.get("status") == "completed" else None,
            "error": data.get("error") if data.get("status") == "failed" else None
        }
```

### Session Token Extraction Steps

1. **Open Flow AI Web App:**
   - Navigate to https://flowai.google.com (or official URL)
   - Login with your account

2. **Extract Bearer Token:**
   - Open DevTools (`F12` → **Network** tab)
   - Generate a test 8-second video
   - Find requests like `POST /api/generate` or `POST /api/tasks`
   - Click request → **Headers** → Copy `Authorization: Bearer <TOKEN>`

3. **Store in Environment:**
   ```bash
   # backend/.env
   FLOW_SESSION_TOKEN=Bearer <YOUR_TOKEN_HERE>
   FLOW_API_URL=https://api.flowai.com/v1/generate
   FLOW_STATUS_URL=https://api.flowai.com/v1/tasks
   ```

4. **Token Refresh Strategy:**
   - Tokens expire after 24-48 hours
   - Admin panel should have a "Refresh Flow Token" button
   - Implement token rotation in background task

```python
import asyncio
import os
from playwright.async_api import async_playwright
from datetime import datetime

class FlowAIAutomation:
    def __init__(self, email: str, password: str):
        self.email = email
        self.password = password
        self.browser = None
        self.page = None

    async def login(self):
        """Automate login to Flow AI website"""
        async with async_playwright() as p:
            self.browser = await p.chromium.launch(headless=True)
            self.page = await self.browser.new_page()
            
            # Navigate to Flow AI
            await self.page.goto("https://flowai.google.com/")
            
            # Wait for login form
            await self.page.wait_for_selector("input[type='email']", timeout=5000)
            
            # Fill credentials
            await self.page.fill("input[type='email']", self.email)
            await self.page.click("button:has-text('Next')")
            
            await self.page.wait_for_selector("input[type='password']", timeout=5000)
            await self.page.fill("input[type='password']", self.password)
            await self.page.click("button:has-text('Sign in')")
            
            # Wait for dashboard load
            await self.page.wait_for_load_state("networkidle", timeout=10000)

    async def generate_video(self, prompt: str) -> str:
        """
        Automate video generation through browser.
        Returns download URL or local file path.
        """
        try:
            # Ensure login
            if not self.page:
                await self.login()
            
            # Navigate to generation page
            await self.page.goto("https://flowai.google.com/generate")
            
            # Fill prompt
            prompt_field = await self.page.query_selector("textarea[placeholder*='Describe']")
            await prompt_field.fill(prompt)
            
            # Click generate
            generate_btn = await self.page.query_selector("button:has-text('Generate')")
            await generate_btn.click()
            
            # Poll for completion (max 2 minutes)
            for attempt in range(40):  # 40 * 3s = 120s
                await asyncio.sleep(3)
                
                # Check if video is ready
                video_element = await self.page.query_selector("video[src]")
                if video_element:
                    video_url = await video_element.get_attribute("src")
                    return video_url
            
            raise Exception("Video generation timed out after 2 minutes")
        
        except Exception as e:
            print(f"Automation error: {e}")
            raise
        
        finally:
            if self.browser:
                await self.browser.close()


async def generate_video_via_automation(prompt: str) -> dict:
    """Wrapper function for FastAPI endpoint"""
    automation = FlowAIAutomation(
        email=os.getenv("FLOW_EMAIL"),
        password=os.getenv("FLOW_PASSWORD")
    )
    
    try:
        video_url = await automation.generate_video(prompt)
        return {
            "status": "success",
            "video_url": video_url,
            "credits_used": 100,  # Approximate
            "duration": "8s"
        }
    except Exception as e:
        return {
            "status": "failed",
            "error": str(e)
        }
```

## 🔐 Security Implementation

### A. Next.js Edge Middleware (Geo-Lock & VPN Detection)

**File:** `frontend/src/middleware.js`

```javascript
import { NextResponse } from 'next/server';

export async function middleware(request) {
  const { pathname } = request.nextUrl;

  // Protect Video Generator route
  if (pathname.startsWith('/tools/video-generator')) {
    // Extract geolocation headers from Vercel/Cloudflare
    const country = request.geo?.country || 
                   request.headers.get('x-vercel-ip-country') || 
                   'UNKNOWN';
    const clientIp = request.ip || 
                    request.headers.get('x-forwarded-for') || 
                    '127.0.0.1';

    // 1. VPN Detection
    const isVpnDetected = 
      request.headers.get('cf-ip-is-vpn') === 'true' || 
      request.headers.get('x-proxy-detected') === '1';

    if (isVpnDetected) {
      console.log(`[VPN BLOCKED] IP: ${clientIp}, Country: ${country}`);
      return NextResponse.redirect(new URL('/blocked-vpn', request.url));
    }

    // 2. Country/Tier Validation
    const allowedFreeCountries = ['US', 'CA', 'AU'];
    const hasPremiumCookie = request.cookies.get('user_tier')?.value === 'premium';

    if (!allowedFreeCountries.includes(country) && !hasPremiumCookie) {
      console.log(`[GEO BLOCKED] Country: ${country}, Premium: ${hasPremiumCookie}`);
      return NextResponse.redirect(new URL('/region-restricted', request.url));
    }
  }

  return NextResponse.next();
}

export const config = {
  matcher: ['/tools/video-generator/:path*'],
};
```

### B. Daily Quota Verification API Route

**File:** `frontend/src/app/api/check-limit/route.js`

```javascript
import { createClient } from '@/utils/supabase/server';
import { NextResponse } from 'next/server';

export async function POST(req) {
  const supabase = createClient();
  
  // Verify user is authenticated
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  // Get today's date in ISO format (YYYY-MM-DD)
  const today = new Date().toISOString().split('T')[0];

  // Fetch today's usage
  const { data: quota, error } = await supabase
    .from('video_quotas')
    .select('count_today')
    .eq('user_id', user.id)
    .eq('generation_date', today)
    .single();

  if (error && error.code !== 'PGRST116') { // PGRST116 = no rows
    return NextResponse.json({ error: "Database error" }, { status: 500 });
  }

  const currentUsage = quota ? quota.count_today : 0;
  const DAILY_LIMIT = 2;

  if (currentUsage >= DAILY_LIMIT) {
    return NextResponse.json({ 
      allowed: false, 
      message: `Daily limit reached (${currentUsage}/${DAILY_LIMIT} videos used). Upgrade to Premium for unlimited.`,
      remaining: 0
    }, { status: 403 });
  }

  return NextResponse.json({ 
    allowed: true, 
    remaining: DAILY_LIMIT - currentUsage,
    current_usage: currentUsage
  }, { status: 200 });
}
```

### C. Increment Quota on Video Start

**File:** `frontend/src/app/api/increment-quota/route.js`

```javascript
import { createClient } from '@/utils/supabase/server';
import { NextResponse } from 'next/server';

export async function POST(req) {
  const supabase = createClient();
  
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const today = new Date().toISOString().split('T')[0];

  // Upsert quota record
  const { error } = await supabase
    .from('video_quotas')
    .upsert(
      {
        user_id: user.id,
        generation_date: today,
        count_today: 1
      },
      { onConflict: 'user_id, generation_date' }
    );

  if (error) {
    return NextResponse.json({ error: "Failed to update quota" }, { status: 500 });
  }

  return NextResponse.json({ success: true }, { status: 200 });
}
```

## 📞 Support & Troubleshooting

### Common Issues

**Q: Flow AI session token expired**
- A: Admin needs to refresh token in dashboard. Implement daily token check in background job.

**Q: Video generation is slow (browser automation)**
- A: Expected for automation. Consider upgrading to API mode if rate permits.

**Q: Users from restricted countries accessing tool**
- A: Verify Vercel geo-headers are enabled. Check middleware logs for bypass attempts.

**Q: Ads not loading**
- A: Verify Google AdSense account approval and slot IDs are correct. Check browser ad blockers.
